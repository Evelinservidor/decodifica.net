# Newsletter semanal

Aqui se guardan las ediciones semanales de la newsletter de Decodifica.

Formato esperado:

```text
numero-YYYY-MM-DD.md
```

Reglas:

- Cada edicion se genera, valida y envia automaticamente a Buttondown.
- Cada archivo debe incluir fuentes revisadas, asunto usado, preheader usado y
  checklist completamente resuelta antes de enviar.
- Si queda sin resolver un claim, una fuente, un enlace, el asunto, el preheader
  o cualquier punto del checklist, el envio se bloquea.
- El publicador es idempotente: una misma edicion no puede enviarse dos veces.
- La newsletter semanal es independiente de los videos de YouTube. Puede enlazar
  uno solo cuando aporte valor editorial real, pero no se genera desde el flujo
  post-YouTube.
