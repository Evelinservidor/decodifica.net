# Newsletter drafts

Aqui se guardan los borradores semanales de la newsletter de Decodifica.

Formato esperado:

```text
numero-YYYY-MM-DD.md
```

Reglas:

- Son borradores de revision, no emails enviados.
- No se envian automaticamente a Buttondown.
- Cada draft debe incluir fuentes revisadas, asunto sugerido, preheader sugerido
  y checklist antes de enviar.
- Jordi revisa, ajusta claims y decide si se copia a Buttondown.
