Claude Skills gratis: qué son, cómo instalarlas y crearlas

Qué son las Skills de Claude, en qué planes funcionan, dónde descargar Skills gratis, cómo instalarlas en Claude.ai y Claude Code, y cómo crear la tuya.

J
Jordi CastañeiraRevisado el 6 oct 2026 · 10 min de lectura

⚡ Respuesta rápida

En resumen: una Skill es una carpeta con un archivo SKILL.md que Claude carga solo cuando tu petición encaja con su descripción. Anthropic incluye cuatro gratis (Word, Excel, PowerPoint y PDF), publica más en el repositorio anthropics/skills y te deja subir las tuyas en Claude.ai, Claude Code y la API.

Free, Pro, Max, Team y Enterprise, con ejecución de código
Dónde
Claude.ai, Claude Code y la API
Ojo

Qué es una Skill de Claude

Anthropic las llama Agent Skills y las define como «carpetas organizadas de instrucciones, scripts y recursos que los agentes pueden descubrir y cargar de forma dinámica» para hacer mejor una tarea concreta.

Lo que las distingue de un prompt largo es cómo se cargan. La documentación lo llama carga progresiva y lo divide en tres niveles: los metadatos (siempre), las instrucciones (al activarse) y los archivos y scripts (solo cuando hacen falta).

Consejo

Puedes tener muchas Skills instaladas: hasta que se activan, cada una solo ocupa unos 100 tokens (su nombre y su descripción).

Dónde funcionan y qué plan necesitas

El centro de ayuda indica que las Skills están disponibles en los planes Free, Pro, Max, Team y Enterprise, siempre que esté activada la ejecución de código.

Ojo

No se sincronizan: una Skill subida a Claude.ai no aparece en la API ni en Claude Code. Hay que instalarla en cada sitio.

Dónde conseguir Skills gratis

El punto de partida más seguro es el repositorio oficial anthropics/skills, porque lo mantiene Anthropic. A 6 de octubre de 2026 contiene 19 Skills, entre ellas skill-creator, que ayuda a crear Skills nuevas.

  1. Abre el repositorio y entra en la carpeta skills/.
  2. Elige una Skill y descarga su carpeta.
  3. Comprímela en ZIP y súbela en Ajustes → Capacidades.

Preguntas frecuentes

¿Las Skills de Claude son gratis?

Sí: las cuatro de Anthropic vienen incluidas y las del repositorio oficial son gratuitas. Necesitas tener activada la ejecución de código.

¿Una Skill es lo mismo que un proyecto?

No. Un proyecto da conocimiento de fondo siempre cargado; una Skill aporta un procedimiento que se activa solo cuando hace falta.
